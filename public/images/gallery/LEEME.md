# Imágenes por proyecto

Cada carpeta contiene cinco imágenes de ejemplo PNG, nombradas con los IDs de content/image-prompts.md.

Sobrescribe el archivo correspondiente con tu imagen final manteniendo el nombre y la extensión .png. No basta con cambiar la extensión de un JPG: expórtalo como PNG. Actualiza el navegador para ver el cambio.
